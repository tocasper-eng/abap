11. SCAL 工廠日曆：查詢、設定順序與程式讀取

講義原文只有三行：「先把假日設成 Public，然後在 Holiday Calendar 拉進來。如何設定，忘了，因為操作都沒有錄影。以下示範如何查詢 Factory。」以下先依截圖整理查詢步驟，再依 SAP 標準補寫設定順序。

11.1 查詢工廠日曆 （依講義步驟整理）

截圖畫面看到什麼
1SCAL → SAP Calendar: Main Menu提示「The calendar is not client-specific／Each change takes effect directly in all clients」；Subobjects 有三個選項：Public holidays、Holiday calendar、Factory calendar；按鈕 Display、Change
2選 Factory calendar → Display—
3工廠日曆清單欄位 ID、Calendar ID（說明）、Valid from、Valid to；例：TW Taiwan 2000～2050、US USA、W6／W7 德國 6／7 天工作制、W8 全年皆工作日、ZR 10-day payment、ZZ ZZ1（2012～2017，已過期的自建日曆）
4雙擊 TW → 年度一覽欄位 Year、Day、Number of Workdays、Number of Free Days；2022 年：Day 6575、工作日 249、休息日 116；2021 年 250／115、2023 年 255／110
5雙擊 2022 → Yearly Overview左側 Calendar Overview（月曆，綠色為休息日，如 2022/10/10 國慶日），右側 Public Holidays 清單：2022/01/01 New Year's Day、01/31 Spring Festival Eve、02/01～02/05 Spring holiday 1～5、02/28 Peace Memorial Day、04/04 Children and Women's Day、04/05 Tomb Sweeping Day (TW)、05/01 May Day、05/02 May Day, moved、06/03 Dragon Boat Festival …
「Day」欄就是工廠日期序號。2022 年列的 Day＝6575、2023 年＝6824，相減 249 恰好是 2022 年的工作日數。也就是說，工廠日曆把每個工作日編成連續整數，DATE_CONVERT_TO_FACTORYDATE 回傳的正是這個號碼；「兩日期間幾個工作天」＝兩個序號相減，「N 個工作天後是哪天」＝序號加 N 再轉回日期。這就是 11.3 程式的原理。

11.2 設定順序 （依講義步驟整理）

  1. Public holidays：SCAL 選 Public holidays → Change，逐一建立假日：固定日期（如 01/01）、固定日期＋星期規則、與復活節的距離、特定年度一次性日期（如補假「May Day, moved」）。每個假日可設宗教代號與優先順序。
  2. Holiday calendar：建立或修改假日日曆（如 TW），按「Assign public holiday」把上一步的假日拉進來，並設定有效年度。這就是講義說的「在 Holiday Calendar 拉進來」。
  3. Factory calendar：建立或修改工廠日曆，指定引用的 Holiday calendar、有效年度，並勾選每週哪幾天是工作日（週六是否上班）；需要時用「Special rules」設定個別日期的例外（如補班日）。
  4. 指派給工廠：OX10（工廠定義）的 Factory Calendar 欄位，即 T001W-FABKL。MRP、排程、交期計算都讀這個欄位。
  5. 傳輸：SCAL 的變更不是自動記錄請求的，要在 SCAL 主畫面用「Transport」功能手動把日曆放進請求；在 QAS／PRD 另外手改會造成各系統日曆不一致。
(1) 日曆不分 Client，在任何一個 Client 改，所有 Client 立即生效（截圖 1 的系統提示）——在 QAS 練習改日曆，同一台機器的所有測試 Client 都會受影響。(2) 截圖 3 的 Valid to 多為 2050，過了有效年度，所有工作日計算都會丟例外（date_after_range）；自建日曆（像截圖中只到 2017 年的 ZZ）要記得每年延長。(3) 台灣每年行政院公布的補班補假都不同，每年年底要在 Public holidays 補登隔年的特殊日期並傳輸。(4) 新版 S/4HANA 的 SCAL 已改為截圖所見的新介面，部分版本另提供 Fiori 應用程式維護日曆，操作入口依系統版本而異，但資料模型與讀取函數不變。

11.3 程式讀取：工廠 → 日曆 → 工作日

相關表格：T001W-FABKL（工廠的工廠日曆）、TFACD（工廠日曆定義）、TFACS（工廠日曆各年度工作日位元）、THOC（假日日曆）、THOL（假日定義）。不要自己解析 TFACS 的位元字串，一律走標準函數（Casper 的第 3 條經驗：先找標準）。2-1 章已示範單一日曆的工作天數；這裡示範實務最常見的寫法：依工廠取日曆，計算「N 個工作天後的日期」。

REPORT zppr0001.
" 依工廠的工廠日曆，計算「起始日 + N 個工作天」的日期
PARAMETERS: p_werks TYPE t001w-werks OBLIGATORY,
            p_date  TYPE sy-datum DEFAULT sy-datum,
            p_days  TYPE i DEFAULT 5.

CLASS lcl_factory_cal DEFINITION FINAL.
  PUBLIC SECTION.
    CLASS-METHODS get_calendar
      IMPORTING i_werks        TYPE t001w-werks
      RETURNING VALUE(r_fabkl) TYPE t001w-fabkl
      RAISING   cx_sy_itab_line_not_found.
    CLASS-METHODS add_workdays
      IMPORTING i_fabkl       TYPE t001w-fabkl
                i_date        TYPE sy-datum
                i_days        TYPE i
      RETURNING VALUE(r_date) TYPE sy-datum.
  PRIVATE SECTION.
    TYPES: BEGIN OF ty_buf,
             werks TYPE t001w-werks,
             fabkl TYPE t001w-fabkl,
           END OF ty_buf.
    CLASS-DATA gt_buf TYPE HASHED TABLE OF ty_buf WITH UNIQUE KEY werks.
ENDCLASS.

CLASS lcl_factory_cal IMPLEMENTATION.
  METHOD get_calendar.
    " 工廠 → 日曆 做成緩衝，大量資料逐筆呼叫時不重複讀 T001W
    IF NOT line_exists( gt_buf[ werks = i_werks ] ).
      SELECT SINGLE werks, fabkl
        FROM t001w
        WHERE werks = @i_werks
        INTO @DATA(ls_t001w).
      INSERT VALUE #( werks = i_werks fabkl = ls_t001w-fabkl ) INTO TABLE gt_buf.
    ENDIF.
    r_fabkl = gt_buf[ werks = i_werks ]-fabkl.
    IF r_fabkl IS INITIAL.
      RAISE EXCEPTION TYPE cx_sy_itab_line_not_found.  " 工廠沒掛日曆
    ENDIF.
  ENDMETHOD.

  METHOD add_workdays.
    DATA lv_facdate TYPE scal-facdate.

    " 起始日若是假日，往後找第一個工作日（correct_option = '+'）
    CALL FUNCTION 'DATE_CONVERT_TO_FACTORYDATE'
      EXPORTING
        correct_option       = '+'
        date                 = i_date
        factory_calendar_id  = i_fabkl
      IMPORTING
        factorydate          = lv_facdate
      EXCEPTIONS
        date_after_range     = 1
        date_before_range    = 2
        OTHERS               = 3.
    IF sy-subrc <> 0.
      RETURN.                                   " r_date 保持空白，由呼叫端判斷
    ENDIF.

    lv_facdate = lv_facdate + i_days.

    CALL FUNCTION 'FACTORYDATE_CONVERT_TO_DATE'
      EXPORTING
        factorydate         = lv_facdate
        factory_calendar_id = i_fabkl
      IMPORTING
        date                = r_date
      EXCEPTIONS
        OTHERS              = 1.
    IF sy-subrc <> 0.
      CLEAR r_date.                             " 超過日曆有效年度
    ENDIF.
  ENDMETHOD.
ENDCLASS.

START-OF-SELECTION.
  TRY.
      DATA(lv_fabkl) = lcl_factory_cal=>get_calendar( p_werks ).
    CATCH cx_sy_itab_line_not_found.
      MESSAGE |工廠 { p_werks } 不存在或未指派工廠日曆（OX10）| TYPE 'S' DISPLAY LIKE 'E'.
      RETURN.
  ENDTRY.

  DATA(lv_due) = lcl_factory_cal=>add_workdays( i_fabkl = lv_fabkl
                                                i_date  = p_date
                                                i_days  = p_days ).
  WRITE: / |工廠 { p_werks }（日曆 { lv_fabkl }）：{ p_date DATE = USER } 起算 { p_days } 個工作天|,
         / COND string( WHEN lv_due IS INITIAL
                        THEN `超出工廠日曆有效範圍，請延長 SCAL 有效年度`
                        ELSE |到期日：{ lv_due DATE = USER }| ).

判斷某一天是不是工作日（例如背景作業只在工作日執行）：

SELECT SINGLE fabkl FROM t001w WHERE werks = '1000' INTO @DATA(lv_cal).

  EXCEPTIONS

IF sy-subrc <> 0.
