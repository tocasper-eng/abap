附錄 A：舊語法 → S/4HANA 現代寫法速查

看舊程式時最常遇到的寫法，以及在 S/4HANA 1809 之後應該改成什麼。左欄不要再寫，右欄照抄即可。

A-1 宣告與指派

舊寫法（不要再寫）現代寫法說明
DATA lv_x TYPE i. lv_x = 1.DATA(lv_x) = 1.內嵌宣告，7.40 起
MOVE a TO b.b = a.MOVE 已過時
ADD 1 TO n.n += 1.複合指派 7.54 起；1809 可寫 n = n + 1
CLEAR wa. wa-a = 1. wa-b = 2.DATA(wa) = VALUE ty_s( a = 1 b = 2 ).VALUE 建構式
MOVE-CORRESPONDING s TO t.t = CORRESPONDING #( s ).可加 MAPPING / EXCEPT / BASE
CREATE OBJECT lo_x.DATA(lo_x) = NEW zcl_x( ).NEW 運算子
CONCATENATE a b INTO c.c = |{ a }{ b }|.字串範本，可直接格式化
IF a = 1. r = 'X'. ELSE. r = ''. ENDIF.r = COND #( WHEN a = 1 THEN 'X' ELSE space ).COND / SWITCH

A-2 內表

舊寫法現代寫法說明
DATA it TYPE TABLE OF ty OCCURS 0 WITH HEADER LINE.DATA it TYPE STANDARD TABLE OF ty WITH EMPTY KEY.表頭列在 OO 與 ABAP Cloud 禁用
LOOP AT it INTO wa.LOOP AT it INTO DATA(wa). 或 ASSIGNING FIELD-SYMBOL(<wa>)大量資料用 field-symbol 免搬移
READ TABLE it INTO wa WITH KEY k = v.
IF sy-subrc = 0.		IF line_exists( it[ k = v ] ).
DATA(wa) = it[ k = v ].		表格運算式；找不到會丟 CX_SY_ITAB_LINE_NOT_FOUND
迴圈逐筆 APPENDDATA(it2) = VALUE ty_t( FOR ls IN it WHERE ( x = 1 ) ( CORRESPONDING #( ls ) ) ).FOR 迭代
迴圈累加DATA(total) = REDUCE d( INIT s = 0 FOR ls IN it NEXT s = s + ls-amt ).REDUCE
排序後 AT NEW 手動分組LOOP AT it INTO DATA(ls) GROUP BY ( k = ls-k ) INTO DATA(grp).內表 GROUP BY，7.40 起
DELETE ADJACENT DUPLICATES FROM it.先 SORT it BY 欄位 再 DELETE ADJACENT DUPLICATES FROM it COMPARING 欄位.沒排序等於沒去重
it[ ... ] 找不到資料會直接丟例外中斷程式，務必搭配 line_exists( ) 或包在 TRY ... CATCH cx_sy_itab_line_not_found。

舊寫法現代寫法說明

SELECT ... ENDSELECT.一次 INTO TABLE，或 SELECT ... INTO ... UP TO n ROWS逐筆迴圈會拖垮效能
SELECT SINGLE * ...SELECT SINGLE 欄位 ... WHERE 完整主鍵主鍵不完整時 HANA 不保證取到同一筆
迴圈內 SELECT SINGLE先整批撈進內表，再用 it[ key = ... ] 或 JOINN+1 查詢是最常見的效能地雷
撈回內表後 LOOP 累加SELECT ... SUM( x ) ... GROUP BY ...Code pushdown：算給資料庫做

A-5 其他常見過時語法

過時改成
TABLES: mara.（宣告表工作區）DATA ls_mara TYPE mara.；TABLES 只在 dialog 程式與選擇畫面必要時使用
PERFORM ... USING ...（FORM）本地類別的方法或全域類別（ABAP Cloud 禁用 FORM）
DEFINE ... END-OF-DEFINITION（Macro）方法；Macro 無法除錯
classic exception（EXCEPTIONS + sy-subrc）TRY ... CATCH cx_...
CALL FUNCTION 'POPUP_TO_CONFIRM' 之外的舊 popup FM仍可用，但新程式建議包成 Z 類別統一管理
DESCRIBE TABLE it LINES n.DATA(n) = lines( it ).
DESCRIBE FIELD ... TYPE ...RTTS：cl_abap_typedescr=>describe_by_data( )
直接 UPDATE / INSERT 標準表一律走 BAPI 或標準 API；直接改標準表會破壞一致性且不受支援
