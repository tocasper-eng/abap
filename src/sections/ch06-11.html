2. SYST 是什麼：sy 的五條規矩

SYST 是 ABAP 字典中的一個結構（SE11 可看），執行時每個內部 session 都有一份，程式中以別名 sy（或 syst）存取。它的欄位由 ABAP 執行環境在執行敘述時自動填值。

  1. 唯讀：除了少數清單控制欄位（如 sy-lsind）SAP 允許在特定事件中改寫之外，一律只讀不寫。改寫 sy-subrc 來「騙」下游判斷，是最常見的壞味道。
  2. 會被覆蓋：sy-subrc、sy-tabix、sy-dbcnt、sy-fdpos 等每執行一個相關敘述就更新，要用就「緊接著用，或立刻存到區域變數」。
  3. 型別請用字典型別：宣告變數時用 TYPE sy-uname 或 TYPE syst_uname（工作表中的 Component Type 欄），不要自己寫 c LENGTH 12。
  4. Obsolete／Internal Use 的欄位不要用：SE11 說明寫著 Obsolete 或 Internal Use 的欄位，SAP 不保證有值，也可能在新版改變行為（第 4 節列出全部）。
  5. sy-repid 不在 SYST 裡：素材匯出的 SYST 沒有 REPID 這個欄位。sy-repid 是每個程式內建的常數（目前程式名），可以照常使用，但不能拿 syst-repid 當型別。

10. 作業一：不用 STRING_REVERSE 的字串反轉

原題示範標準 FM STRING_REVERSE（參數 STRING、LANG、RSTRING），要求在禁用它的前提下自己寫。提示是 strlen 與 DO n TIMES。

原題的兩個陷阱：(1) 題目宣告 l_input(10) TYPE c VALUE 'ABCDEFGHIJK'，但值有 11 個字元，會被截成 ABCDEFGHIJ（語法檢查會警告）；(2) 用固定長度 c 欄位時，如果迴圈跑「欄位長度」而不是 strlen（有效長度，不含尾端空白），反轉後前面會多出一串空白。所以提示才要用 strlen。

解法一：傳統迴圈（strlen＋DO＋substring）

REPORT zca_reverse_loop.

PARAMETERS p_in TYPE c LENGTH 40 LOWER CASE DEFAULT 'ABCDEFGHIJK'.

START-OF-SELECTION.
  DATA(lv_in)  = CONV string( p_in ).     " c 轉 string 時自動去掉尾端空白
  DATA(lv_len) = strlen( lv_in ).
  DATA lv_out TYPE string.

  " 從最後一個字元往前取，逐一接到結果後面
  DO lv_len TIMES.
    DATA(lv_off) = lv_len - sy-index.       " sy-index = 1 時取最後一個字元
    lv_out = lv_out && substring( val = lv_in off = lv_off len = 1 ).
  ENDDO.

  " 另一種寫法：從前往後取，每次接到結果「前面」
  DATA lv_out2 TYPE string.
  DO lv_len TIMES.
    lv_out2 = substring( val = lv_in off = sy-index - 1 len = 1 ) && lv_out2.
  ENDDO.

  cl_demo_output=>write( |輸入：{ lv_in }| ).
  cl_demo_output=>write( |反轉：{ lv_out }| ).
  cl_demo_output=>write( |反轉（前插法）：{ lv_out2 }| ).
  cl_demo_output=>display( ).
為什麼用 substring( ) 而不是 lv_in+lv_off(1) 放進 c 欄位？把單一字元先放進 TYPE c LENGTH 1 變數再用 && 或字串範本串接時，c 型別的尾端空白會被忽略──輸入中間的空白就消失了（'AB CD' 會變成 'DCBA'）。substring( ) 回傳 string，空白會保留。

解法二：內建函數 reverse( ) 與 REDUCE

DATA(lv_in) = `ABCD EFG`.

" 內建字串函數 reverse( )（7.02 起可用，回傳 string）：實務上就用這個
DATA(lv_rev1) = reverse( lv_in ).                       " `GFE DCBA`

" 函數式寫法：FOR 迭代 + REDUCE 累積（練習 7.40 新語法）
DATA(lv_rev2) = REDUCE string( INIT r = ``
                               FOR i = 0 UNTIL i >= strlen( lv_in )
                               NEXT r = substring( val = lv_in off = i len = 1 ) && r ).

" 中文同樣適用：Unicode 系統以「字元」為單位
DATA(lv_rev3) = reverse( `物料主檔` ).                   " `檔主料物`

ASSERT lv_rev1 = lv_rev2.
cl_demo_output=>display( |{ lv_rev1 } / { lv_rev2 } / { lv_rev3 }| ).
這題的真正教訓是 Casper 的第三條實務原則：先找標準，再想客製。STRING_REVERSE 被禁用時，第一個該查的是「有沒有內建函數」（有，reverse( )），而不是馬上寫迴圈。ABAP 的字串函數清單值得從頭看一遍：to_upper( )、condense( )、shift_left( )、repeat( )、translate( )、escape( )、segment( )、count( )、match( )…

12. 建構自己的工具庫：ZCL_CA_UTIL

把本章與前幾章反覆出現的小功能──使用者姓名、民國年日期、月底日、字串反轉、下載──收進一個全域類別。CA 是 Cross-Application（跨模組）的慣用縮寫。原則：

  • 靜態方法、無狀態：工具方法不存資料，用 CLASS-METHODS，呼叫端一行 zcl_ca_util=>xxx( )。
  • RETURNING 優先：能回傳單一值就用 RETURNING，呼叫端可以直接寫在表示式裡。
  • 用例外不用 sy-subrc：失敗時丟自己的例外類別 ZCX_CA_UTIL（SE24 建立，繼承 CX_STATIC_CHECK）。
  • ABAP Doc 寫說明：方法上方用 "! 註解，SE80／ADT 會顯示成 F2 說明。
  • 一定附單元測試：工具庫被很多程式呼叫，改一次錯一片，沒有 ABAP Unit 不要改。
CLASS zcl_ca_util DEFINITION PUBLIC FINAL CREATE PRIVATE.
  PUBLIC SECTION.
    TYPES ty_roc_date TYPE c LENGTH 7.          " 民國年 YYYMMDD，例：1110315

CLASS zcl_ca_util IMPLEMENTATION.

  METHOD get_user_fullname.
    " ADRP 可能有多個生效日版本：先排序再取第一筆（HANA 沒有預設排序）
    SELECT a~name_text, a~date_from
      FROM usr21 AS u
      INNER JOIN adrp AS a
        ON  a~persnumber = u~persnumber
        AND a~nation     = @space
      WHERE u~bname = @iv_uname
      ORDER BY a~date_from DESCENDING
      INTO TABLE @DATA(lt_name)
      UP TO 1 ROWS.
    IF lt_name IS NOT INITIAL.
      rv_name = lt_name[ 1 ]-name_text.
    ENDIF.
    IF rv_name IS INITIAL.
      rv_name = iv_uname.
    ENDIF.
  ENDMETHOD.

  METHOD to_roc_date.
    DATA(lv_year) = CONV i( iv_date(4) ) - 1911.
    rv_roc = |{ lv_year WIDTH = 3 ALIGN = RIGHT PAD = '0' }{ iv_date+4(4) }|.
  ENDMETHOD.

  METHOD last_day_of_month.
    " 當月 1 日 + 31 天一定落在下個月；取下個月 1 日再減 1 天
    DATA lv_next TYPE d.
    lv_next = CONV d( |{ iv_date(6) }01| ) + 31.          " 算術結果轉回 d
    rv_date = CONV d( |{ lv_next(6) }01| ) - 1.
  ENDMETHOD.

  METHOD reverse_string.
    rv_text = reverse( iv_text ).
  ENDMETHOD.

  METHOD download_tab.
    IF sy-batch = abap_true.
      " 背景作業沒有 SAP GUI 前端，請改寫應用伺服器檔案（OPEN DATASET）
      RAISE EXCEPTION TYPE zcx_ca_util.
    ENDIF.
    cl_gui_frontend_services=>gui_download(
      EXPORTING
        filename              = iv_filename
        filetype              = 'ASC'
        write_field_separator = abap_true    " Tab 分隔
        codepage              = '4110'       " UTF-8
        write_bom             = abap_true    " Excel 才認得 UTF-8 中文
      CHANGING
        data_tab              = ct_data
      EXCEPTIONS
        OTHERS                = 1 ).
    IF sy-subrc <> 0.
      RAISE EXCEPTION TYPE zcx_ca_util.
    ENDIF.
  ENDMETHOD.

13. 套件（Package）規劃與命名

工具庫要能跨專案、跨系統帶著走，靠的是套件規劃。命名要與公司命名規則一致（完整範本見 6-4 章）。建議結構：

套件類型放什麼命名範例
ZCA主套件（Main／Structure package）不放物件，只當容器，定義傳輸層—
ZCA_UTIL開發套件通用工具類別、例外類別、訊息類別ZCL_CA_UTIL、ZCX_CA_UTIL、訊息類別 ZCA
ZCA_FILE開發套件檔案、下載、ExcelZCL_CA_FILE、ZIF_CA_FILE
ZCA_DDIC開發套件共用的資料元素、網域、結構、表型別ZCA_S_…（結構）、ZCA_T_…（表型別）、ZCA_DE_…（資料元素）
ZCA_DEMO開發套件示範與自我測試程式，不傳到 PRD（或只留在開發系統）ZCA_…_DEMO
  1. 先建套件再建物件：SE21（或 SE80、ADT）建 ZCA 主套件與子套件，指定軟體元件 HOME 與傳輸層；工具物件絕不要放 $TMP，否則傳不出去。
  2. 前綴統一：類別 ZCL_CA_、介面 ZIF_CA_、例外 ZCX_CA_、函數群組 ZCA_，一眼就知道是共用庫，也方便用 SE84／ADT 搜尋。
  3. 套件介面：規模大時在 ZCA 定義 package interface，只公開真正要給別人用的類別，其餘視為內部。
  4. 各模組套件依賴 ZCA，反之不行：ZCA 內不可呼叫 ZSD、ZMM 的物件，否則共用庫被綁在某個模組上，搬到新專案就編譯不過。
  5. 版本與相容性：公開方法的簽名只加不改（新增選用參數可以，改型別或刪參數不行）；要改就新增方法、舊方法標註淘汰。
  6. 帶著走：個人的工具庫可以用 abapGit 匯出成 Git 儲存庫，新專案匯入後把前綴換成客戶的命名空間即可。
