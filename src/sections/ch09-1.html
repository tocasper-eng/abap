3. 認識六個 TCODE 與寫程式四步驟

講義目錄寫「六個」，內文標題卻寫「五個」，實際列了六個：SE11 資料字典、SE38 建立程式、SPRO 後台配置、SE16N 維護與瀏覽資料、SE16 瀏覽資料、VA03 瀏覽訂單。每個 TCODE 的操作與擴充到十個核心 TCODE 的說明見 第 1-1 章 §1。

寫程式的四步驟：

  1. 取名：程式名稱一定要 Z（或 Y）開頭，屬於客戶命名空間。
  2. 設定屬性：類型選 Executable Program，Status（程式狀態）有四種：
    • P：SAP Standard Production Program（標準生產程式）
    • K：Customer Production Program（客戶生產程式）── 預設選這一項
    • S：System Program（系統程式）
    • T：Test Program（測試程式）
  3. 指定套件：練習環境可全部選 Local Object（套件 $TMP，不會產生傳輸請求，也不能傳到其他系統）。
  4. 執行：啟用（Ctrl+F3）後按 F8 執行。

5. 傳票案例：BKPF／BSEG 與 S/4HANA 的 ACDOCA

講義第 04 節用兩支程式讀傳票：04-01 分別讀 BKPF（表頭）與 BSEG（明細）各自 WRITE；04-02 用 BSEG RIGHT JOIN BKPF 把主子檔關聯起來，並依輸入人員（USNAM）與傳票號碼排序。原程式問題：

  • 04-01 用兩段 SELECT … ENDSELECT，兩段輸出沒有關聯，看不出哪筆明細屬於哪張傳票。
  • 04-02 的 JOIN 條件只有 GJAHR＋BELNR，少了公司代碼 BUKRS；多公司代碼環境會把不同公司的同號傳票串在一起。

  • MANDT 不需要選出也不需要 WRITE，ABAP SQL 會自動處理用戶端。
  • 用 OCCURS 0＋LIKE 宣告帶表頭行的內表，並以年度、日期寫死在程式裡。

13. 自訂權限物件（SU21）與程式中的權限檢查

標準權限物件不夠細時，用 SU21 自建 （依講義步驟整理）：

  1. SU21 建立（或選用）Object Class，例如 ZSD。
  2. 在該 Class 下建立權限物件，例如 Z_SD_VKORG，欄位 VKORG（銷售組織）與 ACTVT（活動）。欄位需先存在於 SU20（權限欄位），VKORG、ACTVT 都是標準欄位可直接用。

    MESSAGE '沒有任何可顯示的銷售組織' TYPE 'S' DISPLAY LIKE 'E'.
    RETURN.
  ENDIF.
